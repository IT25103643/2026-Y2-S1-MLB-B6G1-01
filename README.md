# Movie Reviews NLP Preprocessing Pipeline

## Overview
This project involves a comprehensive, 6-step Natural Language Processing (NLP) preprocessing and feature engineering pipeline. The pipeline transforms raw text-based movie reviews and associated metadata into mathematically structured, numerical datasets ready for downstream Machine Learning models (such as Sentiment Analysis or Ratings Prediction).

The complete workflow covers data cleaning, deduplication, length outlier handling, text normalization (tokenization, stopword removal, lemmatization), categorical encoding, TF-IDF feature extraction, and dimensionality reduction.

## Dataset Details
**Source File:** `Movies_Reviews_modified_version1.csv`

The dataset contains roughly 46,000 raw movie reviews with the following key attributes:
- **`Ratings`**: The target variable (out of 10).
- **`Reviews`**: The raw review text in English.
- **`movie_name`**: The name of the movie.
- **`genres`**: List of genres associated with the movie (stored as strings).
- **`emotion`**: The predominant emotion tag of the review.
- **`Resenhas`** & **`Description`**: Additional text features and Portuguese translations (which are dropped before final ML modeling).

## How to Run the Code

### Prerequisites
Ensure you have Python installed along with the following libraries:
```bash
pip install pandas numpy scikit-learn matplotlib nltk jupyter
```

### Option A: Run the Consolidated Pipeline (Recommended for ML deployment)
For convenience and speed, we have combined all 6 steps into a single, unified pipeline script that processes the data in-memory without saving intermediate CSVs.
1. Navigate to the `Full Pipeline` directory.
2. Ensure the raw dataset `Movies_Reviews_modified_version1.csv` is in this folder.
3. Open and run all cells in `group_pipeline.ipynb`.
4. **Outputs generated:**
   - `movies_reviews_train_final.csv` (Modeling-ready train set)
   - `movies_reviews_test_final.csv` (Modeling-ready test set)
   - `tfidf_vectorizer.joblib` (Fitted vectorizer for inference)
   - All 7 Exploratory Data Analysis (EDA) charts.

### Option B: Run the Pipeline Step-by-Step (Recommended for evaluation)
To review the step-by-step logic and the intermediate data transformations:
1. Ensure the raw dataset `Movies_Reviews_modified_version1.csv` is in the **Data Cleaning & Duplicate Handling** folder.
2. Open the Jupyter Notebooks in sequence (Step 1 through Step 6) from their respective folders.
3. Run all cells in each notebook. 
4. Each notebook will consume the `.csv` generated by the previous step, output a new transformed `.csv` for the next step, and generate EDA visualization charts in its local folder.
